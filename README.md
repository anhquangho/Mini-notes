# WP Mini Notes

A small WordPress notes project built from scratch PHP,
WordPress themes, plugins, custom post types, forms and CRUD.

## Local environment

- WordPress 7.1
- PHP 8.1+
- Apache 8080
- MySQL/MariaDB 3306

## Progress

- [x] Install WordPress locally
- [x] Explore WordPress directory structure
- [x] Create a custom theme
- [ ] Create a notes plugin
- [ ] Implement note CRUD

## Local URL

http://localhost:8080/wp-clone-notion

The WordPress core, uploads and local configuration are not tracked.
